# 📘 Справочник для RMRP — Сервер: Арбат

**Официальная страница распространения приложения.**

Справочник для RMRP — это настольное приложение для удобного хранения, просмотра и систематизации правил, законов и другой информации игрового сервера GTA 5 RMRP.

## 📥 Скачать приложение

**Актуальная версия:** 0.0.0

## ✨ Возможности

- Удобный просмотр правил и законов сервера.
- Структурированная библиотека материалов.
- Локальное хранение пользовательских данных.
- Сохранение собственных изменений и настроек.
- Удобная навигация по справочным материалам.

## 💻 Системные требования

- Операционная система: Windows.
- Необходимое свободное место на диске для установки приложения.
- Права администратора при необходимости установки.

## 📌 Установка

1. Скачайте установщик `RMRP_Arbat_Setup.exe`.
2. Запустите скачанный файл.
3. Следуйте инструкциям установщика.
4. После завершения установки откройте приложение.
